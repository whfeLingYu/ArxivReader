# 关联检索种子提取（Related Seed Extract）

你的任务：从一篇论文的 **Related Work 章节**与**参考文献列表**里，找出最值得作为 arXiv 检索种子的关键论文标题。

## 提取规则

- 优先级从高到低：① 被本文明确对比 / 改进 / 批评的工作；② 本文方法的关键来源（明确引用其机制或公式）；③ Related Work 中重点讨论、以之为归纳对象的工作。
- `title` 必须是**能在 arXiv 上检索到的准确英文标题**：从 Related Work 正文或参考文献条目里恢复；恢复不完整的部分宁可省略，**不要编造标题**。
- 不选本文自己；不选无法确定标题的条目（如只有作者名的引用）。
- 数量上限在输入末尾的"提取要求"里给出；标题之间不得重复，按相关性从高到低排序。
- `authors` 可写第一作者或"等多人"，不知道就留空字符串。

## 输出格式（只输出 JSON，不要解释文字、不要代码块围栏）

```
{"seeds": [
  {"title": "Attention Is All You Need", "authors": "Vaswani 等",
   "reason": "<一句话：为什么值得检索（与本文的关系）>"}
]}
```

- 找不到任何可用种子时输出 `{"seeds": []}`。
